# Product Overview

**SmartKiot** is a mobile Point of Sale (POS) system for small cafes and retail stores in Vietnam. The app enables voice-activated order entry using Vietnamese natural language processing, real-time inventory management, and instant payment processing.

## Core Features

- **Voice Order Entry**: Natural Vietnamese voice commands converted to structured orders (e.g., "Cho 3 ly cà phê sữa và 1 bánh ngọt")
- **Smart Parsing**: Automatic detection of quantities, item names, and prices with Vietnamese number format handling
- **Inventory Management**: Real-time stock tracking with Moving Average Cost (AVCO) calculation
- **Multi-Store Support**: Manage multiple store locations with separate inventories
- **Employee Management**: Role-based access with chat functionality between employees
- **Payment Processing**: VietQR code generation for instant bank transfers
- **Digital Receipts**: Professional bill rendering with image sharing
- **Dashboard Analytics**: Real-time revenue tracking, order statistics, and financial reports
- **Barcode Support**: Product scanning and barcode printing
- **Production Tracking**: Material usage and production transaction management

## Target Users

Small business owners in Vietnam operating cafes, retail stores, or small manufacturing operations who need a mobile-first POS solution with Vietnamese language support.

## Backend

Supabase (PostgreSQL) with real-time sync, authentication, and storage capabilities.
